# brand-takedown v2.0.0 — 安全重构正式版

**适用范围：人工监督的品牌维权取证、案件跟进与投诉草稿。不是无人值守封站系统。**

这是相对于 v1.0.0 的破坏性主版本升级。原审计发现的错案、证据覆盖、访问越界、误判下线和审批脱节问题已按整改台账处理；对未验证的外部能力采用停用或人工审核，不将其冒充已实现。旧 v1.0.0 保留用于历史追溯，不建议用于真实无人值守申诉。

## 更新内容

- UUID 案件及品牌/目录/目标身份绑定；进程与线程锁、版本冲突检查、持久化原子写入；损坏数据明确报错。
- HTTP 每跳白名单和公网地址检查、固定连接 IP、TLS 验证，以及响应大小、总时间和跳转次数限制。
- 每次取证独立快照，保存原始字节和清单摘要；刷新只验证，不覆盖原件或接受篡改；失败取证不能作为有效投诉依据。
- 巡检覆盖全部目标 URL，网络信号不自动关闭整案；反通知、补件和后续复核为独立待办。
- 逐项主张绑定权利、属地和证据；人工批准完整正文、收件目标及附件摘要；实际提交单独记录真实回执。EML 只生成未发送草稿。
- CT 查询失败与零发现分离、候选持续待审；增加 IANA 引导的 RDAP 查询；提供环境能力诊断。
- 移除永久封禁、自动法律责任和不会披露投诉人身份等不可靠承诺；关闭代理、伪装 Referer、自动公开归档和未验证的自动执行路径。

39 项整改台账位于包内 `docs/audit-remediation.md`：24 项限定范围代码修复，14 项限制/人工审核处置，1 项部分完成。分支保护等仓库管理设置不属于本次修复完成项。

## 安装与校验

要求 **Python 3.11+、Linux 或 macOS、本机私有 POSIX 文件系统**。Python 运行时只使用标准库，无需安装第三方 Python 包。不要在 NFS、共享云盘或多主机间并发写同一状态目录。

从本 Release 下载全部四个附件到同一个空目录，然后执行：

```bash
# Linux：验证全部附件
sha256sum -c SHA256SUMS.txt
# macOS：使用下面的命令替代上一行
# shasum -a 256 -c SHA256SUMS.txt

unzip brand-takedown-v2.0.0.zip
cd brand-takedown

# 再验证包内文件；macOS 将 sha256sum 换为 shasum -a 256
sha256sum -c SHA256SUMS.txt
python3 scripts/doctor.py
python3 scripts/brand_registry.py validate --profile-file examples/sample-profile.json
python3 -m unittest discover -s tests -v
```

确认无误后，将整个 `brand-takedown/` 目录放入所用 Agent 实际支持的 Skill 目录，保持 `SKILL.md` 与 scripts/references/templates 的相对结构。不同宿主的目录和工具能力不同，参考 `references/host-contract.md`，不要假定任意宿主都支持某个 Gmail 命令或调度命令。

品牌档案、证书、案件及生成的邮件必须保存在 Skill/仓库之外的私有目录。合成示例只用于验证，不得作为真实权利或案件材料提交。

## 从 v1.x 升级

案件数据结构为 **schema v2**。不自动就地迁移旧数据：先完整备份原私有目录和注册表，在隔离副本核验品牌身份、目标、证据、提交回执及未结法律事项，再使用新的私有目录与注册表重新建档。旧证据只能作为标明来源的历史材料导入，不能用导入时间替代原始采集时间；旧反通知需优先人工核对并录入独立待办。

原 `--status SUBMITTED`、未审批 EML CLI、任意跨案件路径、代理及自动公开归档等不安全接口不再接受。详见 README。

## 验证与边界

发布前必须通过 Ubuntu 24.04 / macOS 15 × Python 3.11 / 3.13 四组验证，每组均执行 150 项测试，并从构建 ZIP 解压后重新运行同一套测试。源码编译、示例校验、摘要清单、私有文件排除和重复打包一致性同时检查。正式公开前，附件从 GitHub 草稿回读并验证摘要；发布后再次回读。

测试使用合成数据、模拟外部响应及本地 loopback HTTP，不发送真实投诉。150 是不同测试的数量，不将多环境重复执行计为更多不同测试。

未实现或未认证的能力包括真实 Gmail 发送/同步、浏览器结账、自动调度、完整司法日历、可信时间戳及 WORM 存储。审批是本地流程记录，不是授权身份数字签名；哈希不是公证。真实法律判断、截止日期和平台处置仍须人工及适当专业审核。本包不包含真实品牌资料、权利证书、案件记录、邮件或凭证。

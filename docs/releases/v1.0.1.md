# brand-takedown v1.0.1 — 安全修复版

**版本规则：按仓库所有者要求，仅做最小补丁号递增：v1.0.0 → v1.0.1。此前误用的 v2.0.0 发布编号予以纠正，不新增业务功能，也不回退已验证修复。**

适用范围为人工监督的品牌维权取证、案件跟进与投诉草稿，不是无人值守封站系统。此次编号更正不代表恢复旧版兼容性；Python 3.11+、案件 schema v2 和人工审批要求均保留。

## 已有修复内容（本次编号更正不修改代码）

- UUID 案件及品牌/目录/目标绑定；进程与线程锁、版本冲突检查、持久化原子写入；损坏数据明确报错。
- HTTP 每跳白名单和公网地址检查、固定连接 IP、TLS 验证，以及响应大小、总时间和跳转次数限制。
- 每次取证独立快照，保存原始字节和清单摘要；刷新只验证；失败取证不能支持有效投诉主张。
- 巡检覆盖全部目标 URL，不自动关闭整案；法律待办独立于网络存活状态。
- 逐项主张绑定权利、属地和证据；人工批准正文、收件目标及附件摘要；实际提交单独记录真实回执。EML 只生成未发送草稿。
- CT 查询失败与零发现分离、候选持续待审；IANA 引导的 RDAP 查询和环境诊断。
- 停用未验证的自动执行路径，删除永久封禁、自动法律责任和不会披露投诉人身份等不可靠承诺。

39 项处置记录见包内 `docs/audit-remediation.md`。本次只调整版本及发布信息；不修改 scripts、tests、templates、references 或已有安全边界。

## 安装与校验

要求 **Python 3.11+、Linux 或 macOS、本机私有 POSIX 文件系统**。仅使用 Python 标准库。禁止在 NFS、共享云盘或多主机上并发写同一状态目录。

下载四个附件到同一目录后：

```bash
# Linux；macOS 使用 shasum -a 256 -c SHA256SUMS.txt
sha256sum -c SHA256SUMS.txt
unzip brand-takedown-v1.0.1.zip
cd brand-takedown
sha256sum -c SHA256SUMS.txt
python3 scripts/doctor.py
python3 scripts/brand_registry.py validate --profile-file examples/sample-profile.json
python3 -m unittest discover -s tests -v
```

将整个 `brand-takedown/` 目录放入 Agent 实际支持的 Skill 目录，保持相对结构；宿主能力要求见 `references/host-contract.md`。品牌私有数据必须保存在仓库和 Skill 之外。合成示例不得作为真实权利材料提交。

## 从 v1.0.0 升级的兼容性注意事项

**补丁号是本仓库的发布编号约定，不表示向后兼容。** 已有修复仍要求 Python 3.11+ 和案件 schema v2。先完整备份旧私有目录和注册表，在隔离副本核验品牌身份、目标、证据、回执及未结法律事项，再在新的私有目录重新建档。旧证据标明来源，不得用导入时间替代原始采集时间；反通知优先人工核对。

未审批 EML CLI、直接设置 SUBMITTED、跨案件路径、代理与自动公开归档等旧接口仍停用。旧 v1.0.0 版本不变；不执行自动就地数据迁移。

## 验证与能力边界

版本纠正发布仍须通过 Ubuntu 24.04 / macOS 15 × Python 3.11 / 3.13 四组验证，每组分别执行源码和 ZIP 解压后的同一套 150 项测试。另检查源码摘要、业务代码未变、私有文件排除和确定性打包；发布附件回读校验后才设为 Latest。

测试仅使用合成数据、模拟外部响应和本地 loopback HTTP，不发送投诉。150 是不同测试数，不累加环境重复执行次数。真实 Gmail 发送/同步、浏览器结账、调度、完整司法日历、可信时间戳及 WORM 存储未实现或未认证；法律判断和截止日期仍须人工及适当专业审核。
